🔗 Propojení (integrace)

        
Napoj appku na GitHub – AI pak umí vytvářet repozitáře a nahrávat kód (tvoje projekty rovnou na GitHub, odkud jdou i zdarma hostovat přes GitHub Pages).

        
        

          
          
        

        
Jak na token: github.com/settings/tokens → „Generate new token (classic)" → zaškrtni repo → zkopíruj. Účet na GitHubu je zdarma.

        

        
🚀 Zveřejnit appku na webu (hosting)

        
Jedním kliknutím nahraje appka sama sebe na GitHub a zapne GitHub Pages – zdarma, natrvalo, s vlastní adresou typu tvujucet.github.io/dark-ai. Repo bude veřejné (free tarif Pages to vyžaduje) – tvoje klíče, chaty ani paměť v něm nejsou, ty zůstávají v tvém prohlížeči.

        
    
          
  1. Založ si účet zdarma: github.com/signup
    2. 
          
  2. Vytvoř token (přednastavený): vytvořit token → dole klikni „Generate token" → zkopíruj ho
    3. 
          
  3. Vlož token do pole GitHub token výše ☝️
    4. 
          
  4. Zmáčkni tlačítko dole – appka se zveřejní sama 🚀
